# Logic Circuit Simulator

A C++ application for designing and simulating logic circuits, built to demonstrate core Object-Oriented Programming (OOP) principles like inheritance and polymorphism.

**Features**

* **Design Mode**
* **Editing:** Add, copy, cut, delete, and label components, or modify connections.
* **Storage:** Save circuits to `.txt` files and reload existing designs.


* **Simulation Mode**
* Execute designed circuits to observe live output behavior on connected LEDs.



**Supported Components**

* **1-Input Gates:** Buffer, Inverter
* **2-Input Gates:** AND, OR, NAND, NOR, XOR, XNOR
* **3-Input Gates:** AND, NOR, XOR
* **I/O & Control:** Switches, LEDs, Wires

**Usage**

Compile and run the project using `graphics_prj.sln`.
